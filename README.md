# Axiom Co-Pilot V2 — iPhone PWA

This is a mobile-first Progressive Web App prototype.

## Install on iPhone
1. Host these files on an HTTPS website.
2. Open the website in Safari.
3. Tap Share → Add to Home Screen.
4. Launch Axiom from the new Home Screen icon.

## Important
This version is a UI/prototype. It does not contain an AI API key and does not have hidden access to the iPhone.

To make it a real AI co-pilot, connect the chat interface to a secure backend that calls your chosen AI service. Never put a private API key directly in the browser app.
